# Visual grammar

The reusable vocabulary begins with `pulse`, `compress`, `rotate`, `accumulate`, `dissolve`, `mirror`, `rupture`, and `reset`. These are behaviors rather than branded objects.

Signal Field demonstrates three independent interpretations: continuous intensity breathes and deforms the field; impact briefly compresses it; song progress changes traversal and negative-space balance. Silence increases openness instead of merely stopping animation.

Future worlds may combine these behaviors into parallax processions, membranes, sacred geometry, organic architecture, mirrors, characters, whiteouts, or forms not yet anticipated. Shared state does not imply shared appearance.
