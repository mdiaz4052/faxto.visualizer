# FaXto Visualizer

FaXto Visualizer is a GUI-first audiovisual interpretation engine. It translates deterministic, precomputed audio measurements into musical and expressive state, then lets independent visual scenes interpret that state. It is deliberately not an FFT-bars visualizer or a single branded aesthetic.

Phase 0 establishes the vertical slice:

`WAV → analyzer → song manifest → musical/expressive state → VisualContext → Signal Field → preview/export`

## Standalone macOS application

Phase 0.1 packages the existing Godot interface as **FaXto Visualizer.app** for
Apple Silicon / macOS 15.0+. The macOS workflow produces an ad-hoc-signed test
archive only after packaging and isolated helper checks pass. Normal use needs
no Godot editor, separately installed Python/NumPy/FFmpeg, Terminal, or network.
See [standalone use, build, signing, and GUI checks](docs/standalone-macos.md).
A successful build is separate from the remaining hands-on macOS acceptance.

For editor development, use Godot 4.7.2 (regular edition) and Python 3.12.14:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r analyzer/requirements-lock.txt
```

Open `godot/project.godot` and run it. The editor-only path finds this `.venv`
or the previous private analyzer environment; release builds use bundled code.
The application retains maximized/stretch-to-window behavior, music-folder
preferences, and configuration compatibility. Export uses a dedicated viewport
and unique output folders with `.gdignore` markers.

## Development checks

```bash
python -m unittest discover -s analyzer/tests -v
python tools/generate_synthetic_wav.py /tmp/synthetic.wav
python analyzer/src/faxto_analyzer/cli.py /tmp/synthetic.wav --output /tmp/song_manifest.json
```

The synthetic WAV is generated by the tests and no commercial FaXto audio belongs in this repository.

## Current limitations

- WAV input is PCM-only in Phase 0.
- Tempo/beat and section estimates are intentionally conservative DSP estimates.
- Export renders deterministic timestamps into PNG frames; standalone builds include H.264/AAC assembly.
- Godot GPU output is not expected to hash identically across hardware. Determinism is asserted at the logical state level.
- Stem slots are represented by source identifiers, but stem analysis is not implemented.

See [architecture](docs/architecture.md), [audio analysis](docs/audio-analysis.md), [visual grammar](docs/visual-grammar.md), and [determinism](docs/determinism.md).
Exact Phase 0 validation versions and environment constraints are recorded in [environment](docs/environment.md).
